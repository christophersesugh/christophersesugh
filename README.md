## About MemoFS

**MemoFS** is a file-first memory runtime for AI agents. It gives agents durable, portable memory using files and structured memory primitives instead of relying entirely on a traditional database.

I’m building MemoFS as an open-source foundation for agents that can retain useful context, manage project knowledge, and coordinate across sessions.
