## What I'm building

- [MemoFS](https://memofs.dev): an open-source memory runtime for AI agents. Memory lives as Markdown and JSONL inside your project, so you can version it, move it, and review changes in a Git diff.
- 0xNAND: a learning platform for software engineering from first principles. It starts with Software Engineering Foundations and is still in development.
- [lab](https://github.com/christophersesugh/lab): the free curriculum from 0xBUFF. It covers Foundations, Systems, AI/ML, and Security, with book maps, labs, projects, and optional mentorship.
- [BuildTrace](https://github.com/0xbuffdev/buildtrace): a Linux-first Rust tool that records what a Cargo build exercises. Pre-alpha.
