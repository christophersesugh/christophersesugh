## 🧠 MemoFS

**[MemoFS](https://memofs.dev)** is an open-source, file-first memory runtime for AI agents. Decisions, facts and context live as plain Markdown and JSONL inside your project, so agent memory is versioned, portable and reviewable in a git diff instead of locked in a hosted database.

- **Project anchoring and drift detection:** memories bind to files, hashes and symbols, and stale ones are demoted before they mislead an agent.
- **Hybrid recall:** BM25 lexical matching fused with vector embeddings, with no database required.
- **Outcome-gated memory:** an isolated scratchpad per agent turn, with only durable facts promoted.
- **Deterministic enforcement:** push hooks across 9+ AI tools, including Claude Code, Cursor, Copilot, Codex and Gemini CLI.
- **Three storage modes:** local, hybrid sync, and a hosted MCP endpoint through [MemoFS Cloud](https://cloud.memofs.dev).

📦 [Docs](https://memofs.dev/docs) · [GitHub](https://github.com/memo-fs/memofs) · [Cloud](https://cloud.memofs.dev) · MIT licensed

## 🎓 Engram

**[Engram](https://engram.memofs.dev)** is a learning platform for engineers who want to understand hard systems from first principles. Lessons move from context and a mental model to visible execution, practice, and a lab you have to defend. Each student's instructor keeps persistent memory of what they've learned and where they struggled. Programs are launching, starting with Software Engineering Foundations.

## 🔬 Also building

**[BuildTrace](https://github.com/christophersesugh/buildtrace)** is a Linux-first Cargo build capability recorder and policy-diff tool. It shows what dependency build scripts and procedural macros actually do during a build, such as files accessed, processes spawned and network calls. *Pre-alpha: `inventory` is implemented, and `record`, `propose` and `diff` are designed but not yet built.* Written in Rust.
